# МойТаксопарк

Учебное Flask-приложение для учёта автопарка и аренды автомобилей. База данных PostgreSQL запускается в Docker, её схема находится в `init.sql`. Оплата работает в учебном режиме: деньги не списываются.

## Запуск

1. Скопируйте `.env.example` в `.env` и укажите собственный пароль базы данных и случайный ключ приложения. Пароль в `POSTGRES_PASSWORD` и в `DATABASE_URL` должен совпадать. Для URL используйте пароль из букв и цифр.
2. Запустите Docker Desktop и выполните `docker compose up -d --build`.
3. Создайте администратора командой `docker compose exec app flask --app app create-user`.
4. Откройте http://localhost:5000. Арендатор может зарегистрироваться самостоятельно.

Остановка: `docker compose down`. Данные базы сохраняются в Docker volume. Файл `init.sql` выполняется при первом создании базы. Перед публикацией приложения необходимо дополнительно настроить безопасность и рабочий веб-сервер.
